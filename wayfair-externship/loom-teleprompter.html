Hi, I'm Dhruv. This is my Phase 4 project for the Wayfair AI Agent Engineering Externship: an AI Insights and Content Agent for the Rugs category.

It takes my Phase 2 market trend report and my Phase 3 competitor report and turns them into a content strategy that sounds like Wayfair.

0:20 · WHAT I FOUND FIRST
Show: hover over Extract Files, AI Content, then Parse Content

Before improving anything, I tested the workflow I was given, and it was producing a completely fake report.

The uploaded files were read from the wrong place, so both reports reached the AI empty.

The prompt was missing an equals sign, so the report text never got inserted.

And when the AI's answer couldn't be parsed, the code quietly swapped in a hard-coded report full of made-up stats like "28% year-over-year growth."

I fixed all three. Now, if a report is empty or the answer is unusable, the run stops with a clear error instead of faking it.

0:55 · MY ENHANCEMENTS
Show: the Upload Form, then the AI Content system message

Then I made it my own. First, I added Target Audience and Season fields to the form, so the content is aimed at someone specific, like first-time renters in fall.

Second, brand voice. I studied Wayfair's blog and Instagram. Wayfair writes like a warm, design-savvy friend: short lines, how the room feels, and soft calls to action like "cozy floors start here."

I turned that into a system message with a persona, platform rules for Instagram, Pinterest, Facebook and TikTok, and a list of banned AI phrases like "elevate" and "curated."

Third, evidence rules. The agent can only use numbers, prices and brands that appear in my reports, and it gets today's date, so it can't schedule a campaign in the past.

1:40 · THE QUALITY CHECK
Show: Parse Content, then the Quality Check box in a report

My favorite addition is an automatic quality check. Instead of trusting the AI, the workflow audits every answer against the source reports.

It flags numbers it can't find, banned phrases that slipped through, past years, and reused example lines, and it shows all of that in a box at the top of the report.

That way a category manager knows exactly what to double-check before publishing.

2:10 · THE OUTPUT
Show: scroll through the latest report

Here's the result. The header shows the audience and season.

The key metrics, like Wayfair's $138.99 average price against Amazon's $63.64 and Walmart's $59.27, come straight from my reports.

The Instagram captions read like Wayfair's real posts, short and casual. TikTok ideas come with a filmable shot list, and each content idea names the report finding it's based on.

2:45 · WRAP-UP
